Create an app against a host product’s contract to use its components, tools, and slots. You need Node.js, a package manager, and the host’s TailorKit API URL. Start with the TailorKit command-line interface (CLI):

```sh
npx tailorkit@beta init
```

Follow the prompts for your app name and the product's TailorKit API URL. The CLI reads its contract, creates a starter app, and generates bindings for its capabilities.

Use these files to add UI, backend logic, and configuration:

| Location | Purpose |
| --- | --- |
| `src/slots/` | UI views, grouped by slot. |
| `src/root.tsx` | The shared UI shell. |
| `src/functions/` and `src/server.ts` | Backend functions and their registration. |
| `src/db/` | Database schema, connection, and migrations. |
| `src/tailorkit.gen.ts` | Generated components, tools, and types; refreshed by `tailorkit generate`. |
| `tailorkit.config.ts` | The host URL and app logos. |
| `vite.config.ts` | Build configuration. |

Start by [writing UI for a slot](/writing-apps/ui).

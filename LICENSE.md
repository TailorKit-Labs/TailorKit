# TailorKit licensing

TailorKit uses per-package licensing. Each package’s `package.json` and `LICENSE.md` identify the license that applies to it.

Generally, TailorKit’s hosted platform and server-side infrastructure use BUSL-1.1, while its SDKs, framework, client libraries, and developer tooling use Apache-2.0.

Files outside a package are licensed under Apache-2.0 unless otherwise noted. Canonical license texts are maintained in `licenses/`.
